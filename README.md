# Single-Page CV

A simple, semantic HTML CV built as part of the [roadmap.sh Single-Page CV project](https://roadmap.sh/projects/single-page-cv).

## Overview

This project involves creating a single-page Curriculum Vitae (CV) using HTML5. The goal is to practice structuring a webpage with semantic HTML elements while applying basic SEO principles and preparing the document for future styling.

## Project Objectives

- Build a well-structured, single-page CV using HTML5.
- Use semantic HTML elements to organize personal information, skills, education, and work experience.
- Implement essential SEO meta tags.
- Add Open Graph (OG) meta tags for social media sharing.
- Include a favicon for browser identification.
- Practice writing clean, readable, and maintainable HTML.

## Technologies Used

- **HTML5** — Page structure and semantic content.

## Features

- **Semantic Structure:** Organizes CV content into meaningful sections.
- **Personal Information:** Displays contact details and professional information.
- **Skills:** Highlights relevant technical and professional skills.
- **Education:** Presents academic qualifications and achievements.
- **Work Experience:** Showcases relevant employment history and responsibilities.
- **SEO Meta Tags:** Provides metadata to help search engines understand the page.
- **Open Graph Tags:** Defines how the CV appears when shared on supported social platforms.
- **Favicon:** Adds a recognizable icon to the browser tab.

## Getting Started

### Prerequisites

- A modern web browser.
- A code editor, such as [Visual Studio Code](https://code.visualstudio.com/).

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_GITHUB_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd Single-Page-CV
   ```

3. Open `index.html` in your web browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension if you have it installed.
